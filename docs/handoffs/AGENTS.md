# Handoffs Rules

Files in this directory are historical or downstream handoff context.

Do not treat handoffs as current source of truth when they conflict with:

1. `AGENTS.md`
2. `docs/README.md`
3. `docs/architecture/2026-04-29-content-factory-producer-restructure.md`
4. `docs/decisions/`
5. `docs/runbooks/`

New handoffs must include a date, purpose, and whether they are current or historical.

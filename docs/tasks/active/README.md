# Active Task Handoffs

Use this folder only for temporary active handoff notes.

Each active task note must include:

- owner or agent role;
- current status;
- next command to run;
- files touched;
- validation still required;
- expiry or cleanup condition.

When the task is done, delete the active note or move durable knowledge to
`docs/architecture/`, `docs/decisions/`, `docs/incidents/`, or `docs/runbooks/`.
